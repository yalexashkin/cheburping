### Приложение для мониторинга доступности выбранного сервера
(писалось для себя. описать мелкие особенности(=баги) в readme проще чем фиксить:) )

Может быть полезно чтобы узнать о включении/выключении белых списков на мобильном интернете раньше всех (особенно учитывая задержки и надежность смс с оповещениями)

Проверенное какое то время назад поведение операторов в конкретном месте:
- Unreachable: yota (и предположительно megafon)
- Timeout: все остальные из проверенных (МТС, Билайн, Теле2)
- На 2G "чебурнета" ни разу не замечено
- в случайные моменты времени таймаут может появиться а потом сам пропасть (предположительно просто сеть такая, похоже случайная одиночная потеря пакета)

Стоящий по умолчанию сервер 8.8.8.8 на моем операторе в какой то момент стал пинговаться по чебурнету так что нужно проверять (вероятно, google.com универсальный вариант)

#### особенности реализации
- при первом запуске может быть надо нажать RUN 2 раза (второй раз после выдачи разрешения)
- android api по непонятным причинам ненадежно определяет тип мобильной сети(2G/3G/4G/..), хотя адекватно различает мобильную и wifi
- если происходит скан и нажать кнопку 'scan now' будет ошибка. просто нажать кнопку снова и тогда попытается просканировать снова
- сканирование не пробуждает аппарат из deep sleep (т.е. за ночь не на зарядке может просканироваться буквально пару раз)
- тамаут сканирования в deep sleep не идет (это относительно большая недоработка)
- AOSP A16 в фоне не прибивает, как другие прошивки - не знаю
